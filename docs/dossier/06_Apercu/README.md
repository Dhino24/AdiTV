# Aperçu local
Ouvrir index.html après extraction complète, dans un navigateur de bureau. Le son nécessite un clic et peut être bloqué selon navigateur. Un bouton sans son et Échap permettent de passer l’intro. La maquette et le logo s’affichent sans réseau ; aucun CDN, compte ni secret requis.
Ce document est une présentation et une animation de concept, pas un prototype des écrans IPTV, un lecteur vidéo ou une application Fire TV. L’animation simplifie le storyboard. Pour la version Android, reproduire les mouvements avec les outils natifs et mesurer sur l’appareil.
