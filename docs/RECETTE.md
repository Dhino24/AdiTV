# Recette sur la Fire TV Stick 4K (1re génération)

À faire avec la version installée, télécommande en main. Noter OK / KO et une remarque.

## Démarrage et navigation
- [ ] Ouverture animée (logo + son), toute touche la passe ; Réglages → Ouverture : image et son désactivables.
- [ ] Barre haute : ↑ depuis l'accueil monte sur « Accueil », ↓ revient sur l'élément quitté.
- [ ] Retour : contenu → barre → Accueil → « Quitter ADITV ? ».
- [ ] Textes lisibles à 3 m (sinon Réglages → Accessibilité → Grande).

## Catalogue
- [ ] Films et séries présents (Réglages → Catalogue local : nombres d'éléments).
- [ ] Top 10 films et séries affichés (clé TMDB), ouvrent la bonne fiche.
- [ ] Fiche film : Lecture / Reprendre, Bande-annonce, Ma liste, Versions.
- [ ] Fiche série : saisons, épisodes, reprise de l'épisode en cours.

## Sport
- [ ] Rangée « Sport en direct » (chaînes françaises) sous l'affiche ; ↑/↓ dans le lecteur passe de l'une à l'autre.
- [ ] Réglages → Sport : FC Barcelone, Real Madrid, PSG, Manchester City, Aston Villa, Sénégal cochés.
- [ ] Rangée « Matchs à venir » quand le guide contient leurs matchs ; rappel automatique visible (cloche).
- [ ] « Me rappeler » sur un programme à venir du guide ; bandeau à l'heure (Menu ≡ pour regarder), y compris pendant une lecture.
- [ ] ADITV fermée : notification à l'heure du rappel ; la choisir ouvre la chaîne.
- [ ] Après redémarrage de la Stick : les rappels sont toujours programmés.

## Direct et guide
- [ ] Couverture du guide affichée, temps d'actualisation noté : ………
- [ ] Filtres Favoris / Sport / Toutes / catégories ; repère « maintenant ».

## Lecture
- [ ] Film, épisode, chaîne lus ; reprise à la bonne position.
- [ ] Audio et sous-titres ; Version (position conservée).
- [ ] Moteur : Auto / Media3 / VLC mémorisé pour le contenu ; un flux refusé par Media3 bascule une fois vers VLC (message affiché).
- [ ] Statistiques (mesuré / estimé / déclaré / N/D) pour chaque moteur.
- [ ] Turbo : comparer les interruptions avec et sans Turbo sur une même chaîne (Réglages → Diagnostic de lecture). Gain mesuré : ………
- [ ] Minuterie de veille : 15 min, fin du programme ; avertissement 60 s avant, une touche prolonge.

## Sauvegarde
- [ ] Réglages → Exporter, puis Importer après réinstallation : préférences, équipes, favoris, Ma liste retrouvés ; aucun accès exporté.
